# Slenter

Leuke plekken op wandelafstand: musea, koffie, eten, bars, parken en meer, rond je huidige locatie. Als lijst, als zoekresultaat met adres, en op een kaart.

- Data: OpenStreetMap via Nominatim (snel) en Overpass (volledig), adressen via Photon.
- Geen build en geen API-sleutels: open `index.html` via een webserver.
